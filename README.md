# Pocket Furry

Pocket Furry is a small virtual companion web app designed for Meta Display, with touch support for phones and browsers.

It focuses on simple interactions, persistent needs, expressive animation, and lightweight ambient behavior.

## Features

- Animated virtual companion
- Persistent hunger, energy, health, cleanliness, and mood
- Interaction menu with feeding, play, petting, cleaning, sitting, sleeping, and medicine
- Touch and swipe controls
- Meta Display / Neural Band navigation support
- Ambient movement and personality-driven behavior
- Local save data using browser storage

## Current Companion

### Noctis

Noctis is the current Pocket Furry companion.

## Controls

### Touch

- Swipe down — open interaction menu
- Swipe left/right — move between actions
- Swipe up — close menu
- Tap — activate selected action
- Long press Noctis — open detailed status

### Meta Display / Neural Band

- Down — open interaction menu
- Left / Right — move between actions
- Up — close menu
- Pinch / Enter — activate selected action

## Files

- `index.html` — app structure
- `style.css` — visual styling
- `app.js` — game logic, animation, input, and persistence
- `assets/` — visual assets

## Running

Pocket Furry is a static web app and can be hosted directly with GitHub Pages or another static web host.

No build process is required.

## Save Data

Game state is stored locally in the browser using `localStorage`.

Clearing site data will reset the companion.

## Project Status

Pocket Furry is actively being developed.

Behavior, animations, controls, and balancing may change as the project evolves.
